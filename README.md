# Гарь — лист движений

Страница для просмотра анимации Боевого клича на телефоне.
Кадры сняты настоящим показом героя в Godot; четыре ракурса,
пауза, замедление и просмотр по кадрам. Все изображения встроены в HTML.

Верхняя поза: корпус почти вертикален, колени слегка согнуты;
кисть с мечом немного выше, левый локоть ниже, меч с небольшим наклоном.

Код игры в этот репозиторий не входит.
